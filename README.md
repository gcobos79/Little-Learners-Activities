# ✨ Little Learners Activities

Quizzes with pictures and sound for Pre-K classrooms. Teachers build activities;
children pick their animal, browse folders, and play on a tablet.

> **Work in progress (V122).** The redesign is being built right now. The original
> ChatGPT version is kept untouched in [`versions/`](versions/).

## Try it

Open `index.html` in Google Chrome (double-click it after downloading), or use the
GitHub Pages link once Pages is turned on for this repository.

- **Students:** tap your animal → pick a folder → pick a quiz.
- **Teacher:** press and hold **🔒 Maestro** for one second.
